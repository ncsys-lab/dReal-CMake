# Module: Tayltst (`group__tayltst`)

Stub. This group documents only the `examples/taylor/tayltst.cpp` example program (free
functions `computeRigorousTrajectory(SetT&, IOdeSolver&, …)`, `computeNonrigorousTrajectory`,
graphing helpers; globals `order = 20`, `step = 0.25`). No library API — it is the source of
the `order` / `step` symbols Doxygen cross-links from other ODE pages. Not relevant to dReal.
