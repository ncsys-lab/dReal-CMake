# NormalForms (group `normalForms`)

**What it is.** Utilities for computing normal forms of planar maps near fixed points
(`takePhiByTwo`, complex `Power`/`Sqr`, `linearSubstitution`, `planarMaps`). dReal-irrelevant
— no normal-form analysis in the solver. Stub only.

**dReal status.** Unused.
